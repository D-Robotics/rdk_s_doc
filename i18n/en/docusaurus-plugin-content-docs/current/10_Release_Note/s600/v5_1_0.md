# RDKS600_LNX_SDK_V5.1.0

**Release Date:** 2026-06-12

## About This Release

D-Robotics RDK S600 V5.1.0, including Linux 6.1.158, Ubuntu root filesystem generated based on multistrap, UBoot-based Bootloader, D-Robotics drivers, some necessary firmware, toolchains, and other releases.

| Description | Supported Versions |
|---|---|
| Supported Host OS for Compilation | Ubuntu 20.04 (x64) |
| Supported Host OS for Burning | Ubuntu 18.04 (x64), Ubuntu 20.04 (x64), Ubuntu 22.04 (x64) |
| Supported Bootloader Version | UBoot 2022.04 |
| Supported Board-Side Root Filesystem | RDKOS V5.1.0 (based on Ubuntu 24.04 (noble)) |
| Supported Board-Side Linux Kernel Version | 6.1.158-rt58 |
| Supported ARM Architecture | aarch64 |
| Cross-compilation Toolchain | [arm-gnu-toolchain-13.2.rel1](https://developer.arm.com/-/media/files/downloads/gnu/13.2.rel1/binrel/arm-gnu-toolchain-13.2.rel1-x86_64-aarch64-none-linux-gnu.tar.xz?rev=22c39fc25e5541818967b4ff5a09ef3e&revision=22c39fc2-5e55-4181-8967-b4ff5a09ef3e&hash=635AD14D80443B785AE05849735087F6) |

## Main Feature Updates/Changes in This Release

- Due to support for NVME boot, the Flash partition table has changed. A full reflash is required for this update.

- Based on compliance requirements, Ubuntu-related fields in the system have been replaced with RDK OS.

- Supports the use of the MAC address stored in the board's eeprom as the default MAC for the board-side ACore network port.

- The ranges for ADC4/5 gears 0x4/0x5/0x6 in boardid have been widened, and gear 0x7 has been removed. Refer to the hardware reference design for details.

### Hardware Support

- Supports V1P0 version hardware

- Supports NVME boot

### ACore

#### Root Filesystem

- Modified the default network configuration scheme to comply with Ubuntu 24.04 NetworkManager and Netplan configuration rules: The manufacturer's default configuration is based on files in the `/usr/lib/NetworkManager` directory, and all final network management configuration files are managed by Netplan.

- Supports hobot-io and its sample functionality porting.

#### Camera

- Added shw3h and shw3f module drivers under the hbn framework.

- Added Mingjing Technology MC30E0Z23-00-03 module driver under the hbn framework.

- Supports Orbbec 335LG depth camera.

#### LSIO

- Supports CAN (c+python) test cases on the Acore side.

- Supports UART and SPI usage on the Acore side.

#### log

- Kernel log storage is now maintained by Ubuntu's native rsyslog. For detailed descriptions, refer to the documentation: [Log Content](https://sdk.d-robotics.cc/sdk_release/rdk_doc/en/Advanced_development/linux_development/log_introduction#log-content)

#### Display

- Added full support for LT9611UXD.

- Optimized display compatibility for various screens.

#### Ethernet/Ethercat

- Added eth0 (gmac2) network port driver support in uboot.

- Default support for ethercat native driver (ec_hobot).

- Fixed the issue of failing to switch to 10M network port speed.

### OTA

- Due to partition table changes, version 5.0.1 cannot be upgraded to 5.1.0 via OTA. A manual flash is required for upgrades. Upgrades within the same version are unaffected.

### MCU

- SBL Image

    - Added GCC compilation support for SBL.

    - Added CPU exception handling information for SBL.

- OS Image

    - Added EL1 Undefined type exception handling information.

    - Added OS CpuLoad feature support.

    - Performance optimization and cache region changes:

        - Changed from global uncached SRAM to local cached (read-only data region/code segment/CPU stack).

- Supports SOEM EtherCAT master.

- Supports multi-channel CAN transparent transmission sample.

### Power

- Supports GPIO interrupt-triggered PMIC_mon function to report PMIC issues.

### Xburn Burning Tool

- v1.2.1: Supports OHP burning.

### Security

- Supports provision tool functionality.

- Supports DFU boot and image download for boards with OHP lifecycle.

### vdsp

- Added vdsp functional support.

## Key Issue Fixes in This Release

### ACore

#### Time Synchronization

- Fixed the issue where output fails when configuring lpwm Acore ETH PPS as a trigger source, and the issue where camera trigger_tv time is not aligned to whole hundred milliseconds. Documentation updated.

#### BPU

- Fixed model inference failures caused by the need to share virtual addresses during BPU multi-core inference.

#### Display

- Fixed a black screen issue caused by sleep/wake.

#### GPU

- Fixed a desktop trailing issue caused by prematurely releasing buffers.

- Fixed a sleep/wake failure issue due to GPU reasons.

### Power

- Fixed occasional PMIC communication failures during cold boot.

- Fixed the issue where the MCU power supply did not complete power-off during the entire system power-off process.

### MCU

#### Peripherals

- SPI4 CS1 abnormal functionality.

#### System

- Fixed double-precision floating-point exception issues.

- Fixed OS context saving compatibility issues with floating-point registers.

- Adjusted the memory layout of mcu1 to adapt to existing functions and resolve conflicts with IPC-allocated memory.

## Known Issues

### Software Known Issues

- RDK OS

    - Some Ubuntu applications crash due to page size mismatches under GPU acceleration.

    - When no HDMI cable is connected, the RDK S600 desktop system (GDM3) defaults to X11 rendering. The S600 currently does not support GPU acceleration for X11, so it falls back to CPU rendering, leading to increased CPU usage.

    - Some RDK S600 10-gigabit network ports have performance issues after startup; firmware must be successfully downloaded to achieve 10-gigabit performance.

    - When using NVMe as the system disk for booting, sleep/wake is not supported.

    - get_multi_vin_data does not support mixed streaming from two mipi hosts.

    - Changing /log to a symbolic link causes the log service to continuously report errors.

- MCU SDK

    - Lockstep unlock is currently not supported.

    - CAN extended frame functionality is currently not supported.
