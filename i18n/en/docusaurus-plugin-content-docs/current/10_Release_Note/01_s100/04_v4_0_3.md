# RDKS100_LNX_SDK_V4.0.3

**Release Date:** 2025-09-01

---

## 1. Key Information

The **RDK S100 V4.0.3** release includes:

- **Linux Kernel:** 6.1.112-rt43
- **Bootloader:** U-Boot 2022.04
- **Root File System:** Based on Ubuntu 22.04 (Jammy), built with Multistrap
- **Supported Host Systems:**
  - Build environment: Ubuntu 20.04 (x64)
  - Flashing environment: Ubuntu 18.04 / 20.04 / 22.04 (x64)
- **Cross-compilation toolchain:** arm-gnu-toolchain-11.3.rel1 (aarch64)
- **Other components:** D-Robotics drivers, necessary firmware, toolchains, and utilities

## 2. New Features

### 2.2 Kernel Configuration

- Reduced the default ION region to 2GiB

### 2.3 Rootfs

- Supports the /boot/config.txt configuration file
  - Supports device tree operations, including overlay, enable, and disable
  - Supports kernel bootargs configuration
  - Supports kernel print level configuration
- Added default on-board kernel module support
  - Support for various CAN controllers
  - Support for various sensor drivers under the IIO framework:
    - IMU driver
    - electronic gyroscope driver
    - accelerometer driver
    - temperature sensor driver
    - distance sensor driver
- Added the hb_switch_ion.sh script to make it easy for customers to modify the ION region size of memory on the board

### 2.4 Main-Domain Peripherals

#### 2.4.1 Camera

#### 2.4.1.1 ISP

- Added an interface to obtain AE brightness information;

#### 2.4.1.2 GMSL Camera

- Supports V4L2 acquisition of depth data and RGB data from the Intel D457 module, and integrates with librealsense
- Supports saving raw YUV422 image data

### 2.5 Sample

- Added computing platform test Samples
- Added multimedia module and pipeline Samples
  - Added Samples for SC230AI and SC132GS
- Supports BPU Python samples
  - 01_classification_sample
  - 02_detection_sample
  - 03_instance_segmentation_sample
  - 04_pose_sample
  - 05_open_instance_seg_sample
  - 06_lane_detection_sample
  - 07_speech_sample
  - 08_OCR_sample

### 2.6 Display Support

- Optimized HDMI display compatibility

### 2.7 MCU-Domain

- MCU system:
  - Supports MCU CPU load data acquisition
  - Supports the MCU hardware floating-point unit
  - Supports ramdump when an MCU exception occurs
  - Stability optimization
- Peripherals
  - Optimized CAN transparent transmission performance and stability
  - SPI supports multiple CS configurations
  - Provides an ADC continuous sampling example

## 3. Key Issue Fixes

### 3.1 Root File System

- Fixed the build error when compiling on-board kernel modules with the linux-headers deb package

### 3.2 Main-Domain

- Fixed the incorrect ramdump stack content issue

### 3.3 Main-Domain Peripherals

- Optimized USB stability
- Camera
  - Fixed the issue where the deserializer and PoC were not powered down after deinit
  - Fixed the time synchronization offset between lidar and camera

### 3.4 MCU-Domain

- MCU system
  - Fixed the inaccurate MCU Alive status retrieval issue
- Peripherals:
  - Fixed the issue where the Port_Func interface returns a value for high-numbered GPIOs that does not match the actual value

## 4. Known Issues

### 4.1 Known Software Issues

- RDK Linux
  - The RTC YSN8130E is not yet supported in software
  - Some Ubuntu applications crash under GPU acceleration due to a page size mismatch
  - The timestamp unit in the CAN transparent transmission multi-channel code does not match the timestamp unit of the Main-Domain middleware; the Main-Domain middleware prints an error, but data transmission is not affected
- MCU SDK
  - The MCU system currently has some stability issues
  - The BMI088 IMU on the MCU daughter board is not yet supported in software
  - Lockstep unlock is not currently supported

## 5. Upgrade Methods

### 5.1 Re-flash

Users can upgrade by re-flashing the complete image:

- Download the image: [RDK_LNX_SDK V4.0.3-Beta](https://archive.d-robotics.cc/downloads/os_images/rdk_s100/RDKS100-V4.0.3-Beta/RDK_LNX_SDK/firmwares/product.zip)
- Flash it by following the [System Flashing](../../01_Quick_start/03_install_os_and_setup/01_instruction.md) chapter

### 5.2 Direct Upgrade

To preserve existing root file system modifications, you can upgrade as follows:

:::warning

This upgrade requires upgrading the miniboot separately using the tool

:::

- Download the new version of the flashing tool: [D-Navigation V2.4.1](https://archive.d-robotics.cc/downloads/software_tools/download_tools/)
- Download the latest image: [RDK_LNX_SDK V4.0.3-Beta](https://archive.d-robotics.cc/downloads/os_images/rdk_s100/RDKS100-V4.0.3-Beta/RDK_LNX_SDK/firmwares/product.zip)
- Follow the U-Boot flashing section of the [System Flashing](../../01_Quick_start/03_install_os_and_setup/01_instruction.md) chapter to perform basic configuration
- In the above configuration, change some options:
  - Upgrade configuration: partition selection
    - Only check: miniboot_flash, miniboot_emmc
- Restart the device after the update is complete
- Run the following commands to get the updates:

  ```bash
  sudo apt update
  sudo apt upgrade
  ```

- Restart the device again to complete the system update
