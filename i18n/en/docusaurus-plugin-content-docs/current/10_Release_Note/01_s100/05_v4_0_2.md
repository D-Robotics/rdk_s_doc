# RDKS100_LNX_SDK_V4.0.2

The RDK S100 Linux SDK includes the following components:

- **RDK Linux**: includes the Linux Kernel, Ubuntu desktop environment, hardware drivers, etc.
- **OpenExplorer (OE)**: model compilation and optimization toolset, algorithm repository, and application development SDK
- **OpenExplorer-LLM (OE-LLM)**: a toolchain for large language models
- **TogetheROS.B**: a ROS2-based robot development kit that provides hardware-accelerated ROS2 packages and pre-trained models
- **D-Navigation**: an image flashing tool

---

## OpenExplorer

### OE Development Toolkit

Provides complete model quantization and deployment development examples, supports the adaptation and optimization of a variety of mainstream models, and helps users quickly build efficient inference pipelines. It includes the following:

- Local development environment installation package
- Model quantization examples based on PTQ (Post-Training Quantization)
- Model quantization examples based on QAT (Quantization-Aware Training)
- Model deployment and performance evaluation examples

### OE User Manual

Provides usage instructions and configuration guidance for each OpenExplorer component, covering installation, toolchain invocation, model adaptation workflows, and more. It is suitable for both beginners and engineering developers.

### CPU Docker Environment

Provides an OpenExplorer Docker image for CPU that integrates the necessary dependencies. It must be used together with the OE development toolkit and is intended for model compilation, quantization, and basic deployment testing.

### GPU Docker Environment

Provides a GPU-oriented Docker runtime environment that supports GPU-based model optimization, inference testing, and tuning workflows. It must also be used together with the OE development toolkit.

## TogetheROS.B

### hobot_sensor

An adaptation component for common robot sensors that supports USB and MIPI camera access, lowering the development barrier, shortening the integration cycle, and helping developers focus on core business logic.

### hobot_dnn

A lightweight inference framework designed specifically for on-device robot inference scenarios, simplifying the deployment of algorithm models, fully unleashing BPU computing power, and lowering the technical barrier to applying intelligent algorithms on the board.

### hobot_codec

A video codec module combining software and hardware that significantly saves CPU resources and improves parallel processing capability. It supports efficient conversion between MJPEG, H264, H265 and image formats such as BGR8, RGB8, and NV12.

### hobot_cv

An acceleration module for common computer vision operators that supports efficient resizing of NV12 images and transcoding between NV12 and BGR24 formats, improving algorithm execution efficiency and reducing system load.

### hobot_render

A visualization rendering module supporting multiple methods for displaying algorithm results in real time, facilitating debugging and demonstrations. It is compatible with mainstream tools such as web browsers, RViz2, and Foxglove Studio.

### Boxs Algorithm Repository

A pre-trained intelligent algorithm library for robot manufacturers and ecosystem developers, helping quickly integrate and deploy various vision and perception models on the D-Robotics RDK system. It covers the following model categories:

- **Object detection**: YOLO series, Faster R-CNN, EfficientDet, etc.
- **Image classification**: MobileNetV2
- **Semantic segmentation**: MobileNet-UNet, YOLOv8-Seg
- **Application algorithms**:
  - Human detection and pose tracking: Yolo-Pose
  - Speech perception processing: SenseVoice
  - Environmental perception and mapping: BEV, CenterPoint
  - Depth estimation and stereo vision: binocular depth estimation
  - Multimodal perception: InternVL vision language model (VLM)
  - SLAM support: feature extraction and matching based on DFMatch

### Apps Application Examples

End-to-end application examples integrating image input, perception processing, and policy decisions, used to demonstrate the complete perception intelligence processing pipeline and help developers quickly build demo projects. Examples include:

- Multimodal intelligent box
- Vision and language interaction system (ASR + VLM/LLM + TTS)

## Known Issues

:::warning

- RDK Linux
  - The RTC YSN8130E is not yet supported in software
  - The BMI088 IMU on the MCU daughter board is not yet supported in software
  - Some Ubuntu applications crash under GPU acceleration due to a page size mismatch
- MCU SDK
  - The MCU system currently has some stability issues
  - The BMI088 IMU on the MCU daughter board is not yet supported in software
  - Lockstep unlock is not currently supported

:::
