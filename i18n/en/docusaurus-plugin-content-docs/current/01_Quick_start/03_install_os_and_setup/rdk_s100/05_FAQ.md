# FAQ

Issues related to serial ports, drivers, and boot failures during flashing and startup are consolidated in the troubleshooting section of the XBurn Manual:

- [Serial and driver issues](https://developer.d-robotics.cc/xburn_doc/troubleshooting/serial-driver) — Ubuntu serial garbled output, Ubuntu 24.04 drivers, macOS CH340N drivers, and so on
- [Boot issues](https://developer.d-robotics.cc/xburn_doc/troubleshooting/boot-issues) — No display output after flashing, boot disk selection, backup image flashing failure, and so on

:::tip
For more issues, visit the [D-Robotics developer forum](https://developer.d-robotics.cc/forum) for help.
:::
