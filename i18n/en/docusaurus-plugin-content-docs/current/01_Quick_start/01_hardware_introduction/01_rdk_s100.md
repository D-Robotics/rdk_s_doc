# Developer Kit Introduction

<img src="https://rdk-doc.oss-cn-beijing.aliyuncs.com/doc/img/01_Quick_start/image/hardware_interface/image-rdk_100_mainboard_overview.png" alt="RDK S100 Developer Kit" style={{ width: '100%', maxWidth: '980px', height: 'auto', display: 'block', margin: '0 auto' }} />

:::warning Warning

1. The RDK S100 uses an external power supply and must comply with the regulatory standards of the relevant region.
2. This product should be used in a well-ventilated environment. When used in an enclosed space, appropriate heat dissipation measures must be taken.
3. During use, this product should be placed on a stable, flat, non-conductive surface.
4. Damage caused by connecting incompatible devices to the RDK S100 will not be eligible for repair.
5. All peripheral devices used with this product must comply with the relevant standards of the country of use and be clearly marked accordingly to ensure safety and performance requirements are met. Peripheral devices include, but are not limited to, keyboards, monitors, and mice used in conjunction with the RDK S100.
6. Cables and connectors of all peripheral devices used with this product must have adequate insulation to meet the relevant safety requirements.

:::

:::warning Safety Instructions

To avoid malfunction or damage to this product, please observe the following:

1. During operation, do not expose it to water or moisture, do not place it on conductive surfaces, and keep it away from any heat source, to ensure reliable operation within normal ambient temperatures.
2. During assembly, avoid mechanical or electrical damage to the printed circuit board and connectors.
3. When powered on, avoid touching the printed circuit board and the edges of the device with your hands to reduce the risk of electrostatic discharge damage.

:::

:::info Tip

For peripherals with an independent external power supply, the development board must be powered on first, followed by the peripherals. If a peripheral is powered on before the S100 development board and causes power backflow into the main board, the development board may enter a protection state and fail to boot.

:::

## Product Introduction

The D-Robotics RDK S100 series developer kit is equipped with the S100 intelligent computing platform. Its BPU delivers up to 80/128 TOPS of computing power. It is a development board designed for intelligent computing and robotics applications, featuring rich interfaces. Its unique heterogeneous design can simultaneously meet the demands of perception inference and real-time motion control, reducing the size and complexity of the control system.

## Interface Description

Interface definition: <a href="https://archive.d-robotics.cc/downloads/hardware/rdk_s100/rdk_s100/drobotics_rdk_s100_pinlist_v1p0_0924.xlsx">drobotics_rdk_s100_pinlist_v1p0.xlsx</a>

### DC Jack (J1)

:::info

The rated voltage is 20V and the rated current is 10A. The S100 main board accepts 12~20V power input. You can use an adapter with an inner diameter of 2.5mm and an outer diameter of 6mm to power the S100 system.

- For typical scenarios, a 70W power supply (12V@5.5A) is recommended.
- For extreme scenarios, a 150W power supply (20V@7.5A) is recommended.

:::

### Automatic EXT CTRL Connector (J2)

The RDK S100 main board has an Automatic EXT CTRL Connector 12-Pin connector, mainly used for the following:

- Extending the system running LED and power indicator LED on the main board to the outside of the board, so that the operating status of the main board can be easily observed.
- Extending the flashing switch, sleep button, reset button, and power switch to the outside of the board for manual operation after the whole system is assembled.

:::info Tip

1. The green LED indicates whether the small system of the main board has completed power-on, and the orange LED indicates whether the Main domain system of the main board is running normally.
2. The power supply of the Automatic EXT CTRL Connector 12-Pin interface is only allowed to be connected to the circuits mentioned in the function description. Connecting high-power loads is prohibited.
3. When the system is in light sleep and deep sleep modes, the VDD_AON_PERI_5V and DCIN_CONN power supplies remain on while the VDD_PERI_3V3 power supply is turned off. When connecting an external daughter board, a short-circuit protection circuit should be reserved to prevent power supply abnormalities on the main board caused by a short circuit on the external daughter board.
4. The maximum output currents of the VDD_AON_PERI_5V, DCIN_CONN, and VDD_PERI_3V3 power supplies are 50mA, 5mA, and 100mA respectively.

:::

### RTC (J3)

The RDK S100 main board includes an RTC external battery connector (J3) for connecting an external RTC backup battery, which keeps the real-time clock running after the main board loses power. The onboard RTC chip is YSN8130E, which communicates via I2C4 with the I2C address `0x32` (excluding the read/write bit).

The pinout for the V1P1 hardware version is as follows:

| Pin No | Signal Name |
| ------ | ----------- |
| 1      | VRTC (3V)   |
| 2      | GND         |
| 3      | GND         |
| 4      | GND         |


:::warning Note

1. A 3V battery is recommended. Each time an external battery is connected to the connector, the battery voltage should be within 2.5-3.5V, and rechargeable batteries must withstand at least 3.3V.
2. For rechargeable batteries, the RTC charging function can be enabled as needed; for non-rechargeable batteries, enabling the charging function is prohibited.
3. When the system is powered on normally, the RTC is preferentially powered by the board-side VDD; after the board loses power, it automatically switches to battery (VBAT) power.
4. After both the main board and the RTC (VBAT) lose power and power is restored, the software must be configured as follows:
    - Write the related registers via I2C to disable the FOUT function, to prevent the extra power consumption caused by battery power, which would affect battery life.
    - If using a rechargeable battery (such as the Waveshare ML2032), re-enable charging; for non-rechargeable batteries (such as the Waveshare CR2032), enabling the charging function is prohibited.
    - If only the board-side VDD loses power while VRTC remains powered, the original configuration is retained and no reconfiguration is required.

:::

### FAN Connector (J8)

The FAN Connector is used to connect a cooling fan and supports fan rotation speed control.

:::info Tip

1. The maximum supply current of 12V is 200mA. When the system is in light sleep and deep sleep modes, the VDD_PERI_12V power supply is turned off.

:::

### Type-C (J16){#type-c-j16}

USB Type-C (J16) is only used for flashing and debugging. It is not a standard full-featured USB Type-C port and includes the following functions:

- Debug serial port. Hardware-wise, two `CH340` chips convert the debug serial ports of the Main domain and MCU domain of the core module into a USB interface. Users can use this interface for various debugging tasks. The first time you use this interface, you need to install the CH340 driver on your computer. You can search for the keyword `CH340 serial driver` to download and install it. The parameters of the serial tool on the computer must be configured as follows:

  - Baud rate: 921600
  - Data bits: 8
  - Parity: None
  - Stop bits: 1
  - Flow Control: None

- USB download interface. The RDK S100 development board provides one download interface for firmware download. For details, refer to [System Flashing](../03_install_os_and_setup/01_instruction.md)

:::tip
The USB Type-C port provided by the RDK S100 development board only supports Device mode.
:::

### M.2 Key E Expansion Slot (J17)

By default, it is used to connect a Wi-Fi module supporting PCIe and a BT module with 4-wire UART. PCIe supports Gen3x1. USB and SDIO interfaces are not provided, and there are no LED or ALERT signals.

:::info

1. To support waking up the S100 from sleep via Wi-Fi/Bluetooth, please contact D-Robotics engineers for support.
2. When the system is in light sleep and deep sleep modes, the VDD_AON_PERI_3V3 power supply remains on, with a maximum supply current of 750mA.

:::

### M.2 Key M Expansion Slot (J18)

Used to connect a PCIe solid-state drive. It supports Gen3x1, has an ALERT signal, and has no LED signal.

:::info

1. Sleep wake-up is not supported.
2. By default, I2C4 is already used for communication with the M.2 KEY M interface, the RTC IC, and the fan (FAN) speed control IC. The I2C addresses of the RTC IC and the fan speed control IC are 0X32 and 0X2F respectively (excluding the read/write bit).
3. When the system is in light sleep and deep sleep modes, the VDD_PERI_3V3 power supply is turned off, with a maximum supply current of 700mA.

:::

### MCU Expansion Header (J22)

The RDK S100 main board includes a 16-pin expansion interface, the MCU Expansion Header, hereinafter referred to as the 16-Pin Header.

- Power signals: VDD_AON_PERI_MCU_3V3, VDD_AON_PERI_MCU_5V.
- Communication interfaces:
  - I2C9, configured with equivalent 3.2K pull-up resistors on the main board
  - SPI3
  - UART5
- PWM signals: PWM6, PWM7.
- GPIO signals: GPIO_MCU_36_3V3, GPIO_MCU_37_3V3.

:::info Tip

1. When the system is in light sleep and deep sleep modes, the VDD_AON_PERI_MCU_3V3 and VDD_AON_PERI_MCU_5V power supplies remain on. The maximum supply currents of VDD_AON_PERI_MCU_3V3 and VDD_AON_PERI_MCU_5V are 300mA and 200mA respectively.
2. When GPIO_MCU_36_3V3 and GPIO_MCU_37_3V3 on the 16-Pin Header are used with external peripherals, the corresponding pins on the peripherals must default to a low state at power-on.
3. When the I2C9_SDA_3V3 and I2C9_SCL_3V3 signals are used as GPIO, external pull-down resistors are not allowed.

:::

### MCU Expansion Connector (J23)

The RDK S100 main board includes a 100-Pin expansion interface, the MCU Expansion Connector, hereinafter referred to as the MCU 100-Pin Connector.

- Power signals: VDD_AON_PERI_MCU_5V, VDD_AON_PERI_MCU_3V3, VDDIO_MCU_3V3, VDDIO_MCU_1V8.
- Network interface: EMAC RGMII interface signals.
- Communication interfaces:
  - I2C8, configured with equivalent 4.7K pull-up resistors on the main board.
  - I2C9, configured with equivalent 3.2K pull-up resistors on the main board.
  - SPI2, SPI4, SPI5
- CAN interfaces: CAN5, CAN6, CAN7, CAN8, CAN9
- Other signals: GPIO, PWM, ADC signals.

:::info Tip

1. The MCU 100-Pin Connector includes IOs with two logic levels: 1.8V and 3.3V. For detailed information, refer to the pin definition file.
2. When the following 14 IOs on the MCU 100-Pin Connector are used with external peripherals, the default high/low state of the corresponding pins on the peripherals at power-on must match the Pull Up/Down state in the pin definition file: SPI5_CSN1_3V3, GPIO_MCU_36_3V3, GPIO_MCU_37_3V3, GPIO_MCU_35_3V3, SPI5_MOSI_3V3, GPIO_MCU_9_3V3, CAN5_TX_3V3, CAN6_TX_3V3, CAN9_TX_3V3, CAN8_TX_3V3, SPI5_CSN0_3V3, CAN7_TX_3V3, GPIO_MCU_6_3V3, GPIO_MCU_7_3V3.
3. When the system is in light sleep and deep sleep modes, the VDD_AON_PERI_MCU_5V and VDD_AON_PERI_MCU_3V3 power supplies remain on, with a maximum supply current of 1000mA each.
4. The maximum supply current of VDDIO_MCU_3V3 and VDDIO_MCU_1V8 is 50mA each, and they are only suitable for low-power applications such as level shifting, pull-up/down resistors, and ADC voltage division. When the system is in light sleep mode, the VDDIO_MCU_3V3 and VDDIO_MCU_1V8 power supplies remain on; when the system is in deep sleep mode, the VDDIO_MCU_3V3 and VDDIO_MCU_1V8 power supplies are turned off.

:::

### Main Expansion Header (J24)

The RDK S100 main board includes a 40-pin expansion interface, the Main Expansion Header, hereinafter referred to as the 40-Pin Header.

- Power signals: VDD_PERI_3V3, VDD_PERI_5V.
- Communication interfaces:
  - I2C5, configured with 4K pull-up resistors on the main board.
  - UART2, configured with 4K pull-up resistors on the main board.
  - SPI0, master mode only.
  - LPWM (GPIO_CAM_4_3V3 and GPIO_CAM_5_3V3).
- Audio interface: The PCM0 related signals are shared with the PCM interface of the Wi-Fi module.
- GPIO signals: 10 GPIOs from 40PIN_GPIO0_3V3 to 40PIN_GPIO9_3V3, provided by a GPIO expansion IC with default 100K internal pull-up resistors.

:::info Tip

2. The I2C5 and UART2 interface pins are multiplexed. The 40-Pin Header and the M.2 KEY E connector share the PCM0 interface, which can be switched via the SW6 DIP switch.
3. When the system is in light sleep and deep sleep modes, the VDD_PERI_3V3 and VDD_PERI_5V power supplies are turned off. The maximum supply current of VDD_PERI_3V3 and VDD_PERI_5V is 1000mA each.
4. When the I2C4_SDA_3V3, I2C4_SCL_3V3, I2C5_SDA_3V3, I2C5_SCL_3V3, UART2_TX_3V3, and UART2_RX_3V3 signals are used as GPIO, external pull-down resistors are not allowed.

:::

### Camera Expansion Connector (J25)

The RDK S100 main board includes a 100-pin expansion interface, the Camera Expansion Connector, hereinafter referred to as the CAM 100-Pin Connector.

- Power signals: VDD_PERI_3V3, VDD_PERI_12V, VDDIO_TOP_1V8.
- Image interface: includes 3 groups of 4lane MIPI RX signals.
- Communication interfaces:
  - I2C1, configured with equivalent 4.7K pull-up resistors on the main board.
  - I2C2, configured with equivalent 4.7K pull-up resistors on the main board.
  - I2C3, configured with equivalent 2.2K pull-up resistors on the main board.
- Other signals: includes LPWM signals, ADC detection signals, Camera Board ID signals, GPIO signals, etc.

:::info Tip

1. The CAM 100-Pin Connector includes IOs with two logic levels: 1.8V and 3.3V. For detailed information, refer to the pin definition file.
2. The maximum supply current of VDDIO_TOP_1V8 is 50mA, and it is only suitable for low-power applications such as level shifting, pull-up/down resistors, and ADC voltage division.
3. When the system is in light sleep and deep sleep modes, the VDD_PERI_3V3, VDD_PERI_12V, and VDDIO_TOP_1V8 power supplies are turned off. The maximum supply current of the 3.3V power supply is 1700mA, and the maximum supply current of the 12V power supply is 800mA.

:::

### Wired Ethernet Ports (U43/U45)

The development board is equipped with two Gigabit Ethernet interfaces, compatible with the 1000BASE-T and 100BASE-T standards, supporting auto-negotiation for speed switching.

| No. | Label | Function Description                             | IP Configuration Method                  | Default IP Address   |
| ---- | ---- | ------------------------------------ | ---------------------------- | -------------- |
| U43  | eth0 | General-purpose Ethernet interface; the user needs to configure the IP address   | External DHCP assignment or manual static configuration | None             |
| U45  | eth1 | Management or dedicated communication interface with a built-in static IP address | Fixed static IP                  | 192.168.127.10 |

### HDMI Interface (J21)

The RDK S100 development board provides one HDMI display interface, supporting display modes up to 2K at 60fps. After power-on, the development board outputs the Ubuntu graphical interface through the HDMI interface. Together with specific sample programs, it also supports preview display of camera and video stream feeds.

### USB Interfaces (J19/J20)

The RDK S100 development board provides four USB 3.0 standard interfaces expanded via PCIe, allowing up to 4 USB peripherals to be connected and used simultaneously. Each USB 3.0 interface supports a maximum output of 5V/1A.

:::tip

1. The USB 3.0 interfaces provided by the RDK S100 development board only support Host mode.
2. Note the [USB 2.0 Camera Access Limitation](/Demos/peripheral/camera/usb_camera#usb-2.0-note).
   :::

## Switches, Buttons, and LEDs

### Buttons (K1/K2)

| No. | Name  | Description                                | Usage                       |
| ---- | ----- | ----------------------------------- | ------------------------------ |
| K1   | RESET | Reset the S100 system                      | After pressing the button, the system enters reset       |
| K2   | SLEEP | Control the S100 system to enter sleep or wake up the S100 | A single-press interrupt triggers the sleep and wake-up functions |

### Switches (SW1/SW2)

| No. | Name     | Description             | Usage                         |
| ---- | -------- | ---------------- | -------------------------------- |
| SW1  | ON/OFF   | Power switch         | ▽: ON, ↑: OFF                 |
| SW2  | DOWNLOAD | DFU flashing mode switch | ▽: Normal boot mode, ↑: DFU flashing mode |

### DIP Switches (SW3/SW6)

#### Boot Device Selection (SW3)

:::info

Currently only eMMC boot is supported

:::

| D13 | D12 | Boot Medium | Description                     |
| --- | --- | -------- | ------------------------ |
| 0   | 1   | eMMC     | Boot from the onboard eMMC         |
| 1   | 0   | NVMe     | Boot from an M.2 NVMe solid-state drive |

#### Function Selection (SW6)

The I2C5 and UART2 interface pins on the 40-Pin are multiplexed. The 40-Pin (J24) and the M.2 KEY E connector (J17) share the PCM0 interface, which can be switched via the SW6 DIP switch.

:::info Recommendation

For PCM0, if you do not need the Bluetooth audio function of the Wi-Fi module, you can keep the DIP switch switched to the right by default.

:::

| Switch Name | 1                                | 0                                  |
| -------- | -------------------------------- | ---------------------------------- |
| 40 PIN   | Pins 3 and 5 of the 40-Pin are active, for I2C5 | Pins 8 and 10 of the 40-Pin are active, for UART2 |
| PCM0     | PCM0 used for M.2 E Key              | PCM0 used for 40PIN                    |

### Indicator LEDs

On the side of the J8 connector of the RDK S100 main board, there are three indicator LEDs: POWER, DOWNLOAD, and SYSTEM, which indicate the main board power status, DFU flashing mode, and system running status respectively.

#### POWER (Green)

| Status | Status Description |
| :--- | :------- |
| Steady On | Power on |
| Off | Power off |

#### DOWNLOAD (Red)

| Status | Status Description          |
| ---- | ----------------- |
| Steady On | DFU flashing mode is entered |
| Off | Normal boot mode is entered  |

#### SYSTEM (Orange)

| Status       | Status Description     |
| ---------- | ------------ |
| Blinking       | System running normally |
| Steady On, Off | System running abnormally |
