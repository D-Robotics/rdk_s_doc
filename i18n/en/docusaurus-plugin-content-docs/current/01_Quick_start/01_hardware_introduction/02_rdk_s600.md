:::warning Warning

1. The RDK S600 uses an external power supply and must comply with the regulatory standards of the relevant region.
2. This product should be used in a well-ventilated environment. When used in an enclosed space, appropriate heat dissipation measures must be taken.
3. During use, this product should be placed on a stable, flat, non-conductive surface.
4. Damage caused by connecting incompatible devices to the RDK S600 will not be eligible for repair.
5. All peripheral devices used with this product must comply with the relevant standards of the country of use and be clearly marked accordingly to ensure safety and performance requirements are met. Peripheral devices include, but are not limited to, keyboards, monitors, and mice used in conjunction with the RDK S600.
6. Cables and connectors of all peripheral devices used with this product must have adequate insulation to meet the relevant safety requirements.

:::

:::warning Safety Instructions

To avoid malfunction or damage to this product, please observe the following:

1. During operation, do not expose it to water or moisture, do not place it on conductive surfaces, and keep it away from any heat source, to ensure reliable operation within normal ambient temperatures.
2. During assembly, avoid mechanical or electrical damage to the printed circuit board and connectors.
3. When powered on, avoid touching the printed circuit board and the edges of the device with your hands to reduce the risk of electrostatic discharge damage.

:::

:::info Tip

For peripherals with an independent external power supply, the development board must be powered on first, followed by the peripherals. If a peripheral is powered on before the S600 development board and causes power backflow into the main board, the development board may enter a protection state and fail to boot.

:::

## Product Introduction

The D-Robotics RDK S600 series developer kit is equipped with the S600 intelligent computing platform. Its BPU delivers up to 560 TOPS of computing power. It is a development board designed for intelligent computing and robotics applications, featuring rich interfaces. Its unique heterogeneous design can simultaneously meet the demands of perception inference and real-time motion control, reducing the size and complexity of the control system.

## Interface Description{#interface}

Interface definition: <a href="https://archive.d-robotics.cc/downloads/hardware/rdk_s600/rdk_s600/D-Robotics_RDK_S600_Connector_Application_Note_V1P0-20260612.xlsx">D-Robotics_RDK_S600_Connector_Application_Note_V1P0.xlsx</a>

### Main Board Power Interface (J1)

:::info Tip

- The RDK S600 developer kit supports a 12V-28V power supply with a maximum current of 16A, using a 4-pin Microfit Connector.
- The power adapter provided by D-Robotics has a rated output voltage of 24V and a maximum output current of 8A.

:::

### 699-Pin B2B Connector (J2)

The RDK S600 developer kit provides a 699-Pin connector, used to connect to the RDK S600 core board.

:::info Tip

To use the 699-Pin B2B Connector, please contact your FAE in advance for more detailed materials.

:::

### JTAG Interface MCU&MAIN (J3)

The RDK S600 developer kit provides a 10-Pin connector, used for JTAG debugging of the Main and MCU domains on the RDK S600 core board.

### Flash Port: Flashing, Main&MCU Debugging (J4){#j4}

USB Type-C (J4) is only used for flashing and debugging. It is not a standard full-featured USB Type-C port and includes the following functions:

- Debug serial port. Hardware-wise, two `CH340` chips convert the debug serial ports of the Main domain and MCU domain of the core module into a USB interface. Users can use this interface for various debugging tasks. The first time you use this interface, you need to install the CH340 driver on your computer. You can search for the keyword `CH340 serial driver` to download and install it. The parameters of the serial tool on the computer must be configured as follows:

  - Baud rate: 921600
  - Data bits: 8
  - Parity: None
  - Stop bits: 1
  - Flow Control: None

- USB download interface. The RDK S600 development board provides one download interface for firmware download. For details, refer to [System Flashing](../03_install_os_and_setup/01_instruction.md)

:::info Tip
The USB Type-C port provided by the RDK S600 developer kit only supports Device mode.
:::

### M.2 Key E Interface (J5)

By default, it is used to connect a Wi-Fi module supporting PCIe and a BT module with USB 2.0, and it also supports 4-wire UART BT modules. PCIe supports Gen3x1. It also provides an SDIO interface and a PCM audio interface. There are no LED or ALERT signals.

:::info Tip

1. To support waking up the S600 from sleep via Wi-Fi/Bluetooth, please contact D-Robotics engineers for support.
2. When the system is in light sleep and deep sleep modes, the VDD_AON_PERI_3V3 power supply remains on, with a maximum supply current of 750mA.

:::

### M.2 Key M Interface (J6)

Used to connect a PCIe solid-state drive. It supports Gen4x2, has an ALERT signal, and has no LED signal.

:::warning Note

Sleep wake-up is not supported.
:::

:::info Tip

When the system is in light sleep and deep sleep modes, the VDD_PERI_3V3 power supply is turned off, with a maximum supply current of 700mA.

:::

### USB 3.0 Type-A Interfaces (J7/J8/J9)

The RDK S600 development board provides six USB 3.0 standard interfaces expanded via PCIe, allowing up to 6 USB peripherals to be connected and used simultaneously. Each USB 3.0 interface supports a maximum output of 5V/1A.

:::info Tip

- The USB 3.0 interfaces provided by the RDK S600 development board only support Host mode.
- Note the [USB 2.0 Camera Access Limitation](../../03_Demos/01_peripheral/02_camera/02_usb_camera.md#usb-2.0-note).
  :::

### HDMI Interface (J10)

The RDK S600 developer kit provides one HDMI display interface, supporting display modes up to 2K at 60fps. After power-on, the developer kit outputs the Ubuntu graphical interface through the HDMI interface. Together with specific sample programs, it also supports preview display of camera and video stream feeds.

### MIPI Camera Interfaces (J11/J13){#mipi-camera-interfaces-j11j13}

The RDK S600 includes 2 camera expansion interfaces, which can connect monocular or binocular cameras. Each MIPI camera interface provides 1 MIPI D-PHY, 1 I2C, and 1 3.3V power supply. See [Interface Description](#interface) for the signal definitions of the MIPI camera interfaces.

:::info Tip

- The I2C level standard is 3.3V.
- The maximum current of the 3.3V supply is 1A.  
:::

### Camera Expansion Interfaces (J12/J14)

The RDK S600 developer kit includes 2 camera expansion interfaces. The camera expansion interfaces use 80-Pin board-to-board connectors, and each camera expansion interface can provide the following functions. See [Interface Description](#interface) for the signal definitions of the camera expansion interfaces.

- 2x D-PHY, or configurable to 1x D-PHY + 1x C-PHY.
- 2x I2C interfaces.
- 4x PWM signals for camera triggering.
- 2x sensor error signals.
- 2x deserializer lock signals.
- 2x deserializer error signals.
- 2x deserializer PWRON signals.
- 2x POC EN signals.
- 2x POC INT signals.
- 12V supply, supporting up to 2A.
- 3.3V supply, supporting up to 1A.
- 1.8V supply, supporting up to 50mA, used for signal pull-up/pull-down.

:::info Tip

 The maximum supply capability of 12V is 2A. Please pay attention to the total power consumption of the sensors used.

:::

### MCU Expansion Interface (J15)

The RDK S600 developer kit includes an 80-Pin expansion interface, the MCU Expansion Connector, hereinafter referred to as the MCU 80-Pin Connector

- Power signals: VDD_MCU_PERI_5V, VDD_MCU_PERI_3V3, VDDIO_MCU_3V3, VDDIO_MCU_1V8
- Communication interfaces:
  - I2C13, configured with equivalent 2.2K pull-up resistors on the main board.
  - I2C14, configured with equivalent 2.2K pull-up resistors on the main board.
  - SPI4, SPI6, SPI8, SPI13.
- CAN interfaces: CAN1, CAN2, CAN3, CAN4, CAN10
- Other signals: GPIO, PWM, ADC, PPS signals

:::info Tip

1. The MCU 80-Pin Connector includes IOs with two logic levels: 1.8V and 3.3V. For detailed information, refer to [Interface Description](#interface).
2. When the system is in light sleep, the VDD_MCU_PERI_5V and VDD_MCU_PERI_3V3 power supplies remain on, with a maximum supply current of 1000mA each.
3. When the system is in deep sleep, the VDD_MCU_PERI_5V and VDD_MCU_PERI_3V3 power supplies are turned off.
4. The maximum supply current of VDDIO_MCU_3V3 and VDDIO_MCU_1V8 is 50mA each, and they are only suitable for low-power applications such as level shifting, pull-up/down resistors, and ADC voltage division. When the system is in light sleep mode, the VDDIO_MCU_3V3 and VDDIO_MCU_1V8 power supplies remain on; when the system is in deep sleep mode, the VDDIO_MCU_3V3 and VDDIO_MCU_1V8 power supplies are turned off.

:::

### MCU-CAN Interface (J16)

The RDK S600 developer kit includes a CAN bus interface in the MCU domain. This interface uses a 12-Pin self-locking connector and provides 5 CAN interfaces in the MCU domain. The connection of the 120Ω resistors can be controlled by the SW6 switch. See [Interface Description](#interface) for the signal definitions of the MCU-CAN interface.

<img src="http://rdk-doc.oss-cn-beijing.aliyuncs.com/doc/img/01_Quick_start/image/hardware_interface/image_rdk_s600-J16-pin1.jpg" alt="RDK S600 MCU-CAN interface pin diagram" style={{ width: '60%', maxWidth: '980px', height: 'auto', display: 'block', margin: '0 auto' }} />

### MAIN-CAN Interface (J17)

The RDK S600 developer kit includes a CAN bus interface in the MAIN domain. This interface uses a 10-Pin self-locking connector and provides 4 CAN interfaces in the MAIN domain. The connection of the 120Ω resistors can be controlled by the SW7 switch. See [Interface Description](#interface) for the signal definitions of the MAIN-CAN interface.

<img src="http://rdk-doc.oss-cn-beijing.aliyuncs.com/doc/img/01_Quick_start/image/hardware_interface/image_rdk_s600-J17-pin1.jpg" alt="RDK S600 MAIN-CAN interface pin diagram" style={{ width: '60%', maxWidth: '980px', height: 'auto', display: 'block', margin: '0 auto' }} />

### UART Interface MAIN&MCU (J18)

The RDK S600 developer kit includes a UART interface for the MAIN domain and the MCU. This interface uses a 10-Pin self-locking connector and provides 2 UART interfaces in the MCU domain and 2 UART interfaces in the MAIN domain. See [Interface Description](#interface) for the signal definitions of the UART interfaces.

<img src="http://rdk-doc.oss-cn-beijing.aliyuncs.com/doc/img/01_Quick_start/image/hardware_interface/image_rdk_s600-J18-pin1.jpg" alt="RDK S600 UART interface pin diagram" style={{ width: '60%', maxWidth: '980px', height: 'auto', display: 'block', margin: '0 auto' }} />

### PCM+I2C Interface (J19)

This interface uses a 14-Pin self-locking connector and provides 2 PCM interfaces and 1 I2C interface, used to connect audio-related function daughter cards. See [Interface Description](#interface) for the signal definitions of the PCM audio interface.

<img src="http://rdk-doc.oss-cn-beijing.aliyuncs.com/doc/img/01_Quick_start/image/hardware_interface/image_rdk_s600-J19-pin1.jpg" alt="RDK S600 PCM+I2C interface pin diagram" style={{ width: '60%', maxWidth: '980px', height: 'auto', display: 'block', margin: '0 auto' }} />

### RTC Battery Interface (J20)

The RDK S600 developer kit includes a battery interface for connecting an external RTC battery.

### Fan Interface (J21)

The FAN Connector is used to connect a cooling fan and supports fan rotation speed control.

:::info Tip

The maximum supply current of 12V is 200mA. When the system is in light sleep and deep sleep modes, the VDD_PERI_12V power supply is turned off.

:::

### Main Board Function Interface (J22)

The RDK S600 developer kit main board has an Automatic EXT CTRL Connector 12-Pin connector, mainly used for the following:

- Extending the system running LED and power indicator LED on the main board to the outside of the board, so that the operating status of the main board can be easily observed.
- Extending the flashing switch, sleep button, reset button, and power switch to the outside of the board for manual operation after the whole system is assembled.

:::info Tip

1. The green LED indicates whether the small system of the main board has completed power-on, and the orange LED indicates whether the Main domain system of the main board is running normally.
2. The power supply of the Automatic EXT CTRL Connector 12-Pin interface is only allowed to be connected to the circuits mentioned in the function description. Connecting high-power loads is prohibited.
3. When the system is in light sleep and deep sleep modes, the VDD_AON_PERI_5V and DCIN_CONN power supplies remain on while the VDD_PERI_3V3 power supply is turned off. When connecting an external daughter board, a short-circuit protection circuit should be reserved to prevent power supply abnormalities on the main board caused by a short circuit on the external daughter board.
4. The maximum output currents of the VDD_AON_PERI_5V, DCIN_CONN, and VDD_PERI_3V3 power supplies are 50mA, 5mA, and 100mA respectively.

:::

### 2x 1GbE (U44)

Two Gigabit Ethernet interfaces, compatible with the 1000BASE-T and 100BASE-T standards, supporting auto-negotiation for speed switching.

| Position | Label | Function Description                             | IP Configuration Method                  | Default IP Address   |
| ---- | ---- | ------------------------------------ | ---------------------------- | -------------- |
| Lower   | eth0 | General-purpose Ethernet interface; the user needs to configure the IP address   | External DHCP assignment or manual static configuration | None             |
| Upper   | eth1 | Management or dedicated communication interface with a built-in static IP address | Fixed static IP                  | 192.168.127.10 |

### 2x 10GbE (U45)

This interface provides 2 10-Gigabit Ethernet ports.

### 1x 1GbE MCU (U80)

This interface is the MCU domain Gigabit Ethernet port.
