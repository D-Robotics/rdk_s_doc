# Next Steps

After completing Quick Start, you already have a working RDK development board: the system is flashed, initial setup is done, and you can log in remotely. What to do next depends on your goals and your role.

The RDK documentation is organized around three development modes. Use the table below to find the path that fits you:

| Mode | Readers | Goal | Where to go next |
|---|---|---|---|
| Mode 1 Direct Use | Individual developers, geeks, students | Run demos, build prototype evaluations | [Demos](/Demos); check out [Simple API](/Simple_API) when you want to write your own code |
| Mode 2 Product Integration | Product companies, R&D teams | Productize and customize based on the image | [System Configuration](/System_configuration) + [System Software Development](/Advanced_development/system_software) |
| Mode 3 Deep Customization | Commercial customers, deep-diver teams | Deep secondary development | [Advanced Development](/Advanced_development) |

## Contents of This Section

The "Next Steps" section offers you two further entry points:

- [Using RDK Studio](./01_rdk_studio.md): when you want an integrated development environment (IDE) to complete code editing, compilation, debugging, and model deployment in one place.
- [Using TogetheROS.Bot](./02_trosb.md): when you want to build robot applications, developing perception, planning/control, and mapping with the tros.b middleware.
