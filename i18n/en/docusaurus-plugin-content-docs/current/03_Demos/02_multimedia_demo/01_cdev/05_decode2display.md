# Decode→Display

This example demonstrates decoding a video bitstream (H.264/H.265) and outputting it to an HDMI display in real time. Pipeline: File → Decoder → Display.

:::tip
The example source code is pre-installed in the `/app/cdev_demo/decode2display/` directory on the board, and can be compiled and run directly with `make`.
:::

## Prerequisites

- The development board is flashed with RDK OS and booted (see [Getting Started with RDK](../../../01_Quick_start/02_getting_started.md))
- An HDMI display is connected
- An H.264/H.265 bitstream file is available (you can use the output generated by [Capture→Encode](./03_vio2encoder.md), or the pre-installed `/app/res/assets/1080P_test.h264` on the board)

## Code Location

On-board path: `/app/cdev_demo/decode2display/`

```
decode2display/
├── Makefile
└── decoder2display.c
```

## Build and Run

```bash
cd /app/cdev_demo/decode2display
make
./decoder2display -w 1920 -h 1080 -i /app/res/assets/1080P_test.h264
```

Parameter description:

| Parameter | Description |
| --- | --- |
| `-i` | Input bitstream file path (H.264/H.265, auto-detected by extension) |
| `-w` | Input video width |
| `-h` | Input video height |

After the program starts, the decoded bitstream is displayed on the HDMI display in real time. Press `Ctrl+C` to exit. When the video resolution differs from the display resolution, the example automatically creates a VPS channel to scale it.

## Code Walkthrough

The example uses the Simple API (`sp_codec.h` / `sp_display.h` / `sp_vio.h` / `sp_sys.h`). Core flow:

1. `sp_init_decoder_module` — initialize the decoder module
2. `sp_init_display_module` + `sp_start_display` — initialize and start the display
3. `sp_start_decode` — open the bitstream file and start decoding
4. When resolutions mismatch, `sp_open_vps` creates a VPS scale channel
5. `sp_module_bind` — bind decoder to display (DECODER → DISPLAY, or DECODER → VPS → DISPLAY)
6. `sp_stop_decode` / `sp_stop_display` / `sp_release_*_module` — release resources

See [DECODER API](../../../04_Simple_API/01_multimedia_api/cdev/03_decoder_api.md) and [DISPLAY API](../../../04_Simple_API/01_multimedia_api/cdev/04_display_api.md) for interface details.

## FAQ

### Log warning `vot_chn values 0-3 is deprecated`

**Cause**: The example passed a legacy channel number when calling `sp_start_display`, and the driver automatically handles it as HDMI mode.

**Solution**: This warning does not affect functionality and can be ignored.

### `sp_start_decode failed` message

**Cause**: The input bitstream file does not exist, or `-w` / `-h` does not match the actual resolution of the bitstream.

**Solution**: Confirm the file path is correct and the width/height parameters match the bitstream.
