# I2C Application

By default, the RDK S100 enables I2C5 (physical pins 3 and 5) and I2C4 (physical pins 27 and 28) on the 40PIN, with 3.3V IO levels.

:::info

- On the 40-pin header, you need to toggle the DIP switch to select between I2C5 and UART2. See the figure below for the details:

<img src="https://rdk-doc.oss-cn-beijing.aliyuncs.com/doc/img/07_Advanced_development/02_linux_development/driver_development_s100/audio3.png" alt="I2C application diagram" style={{ width: '40%', maxWidth: '980px', height: 'auto', display: 'block', margin: '0,0' }} />

For pin definitions, refer to [Pin Configuration and Definitions](./01_40pin_define.md#40pin_define)

:::

See `/app/40pin_samples/test_i2c.py` for detailed information on how to use I2C.

:::tip
The pins mentioned below are for illustration only; port values differ across platforms, and the actual situation prevails. You can also directly use the code under the `/app/40pin_samples/` directory, which has been verified on the board.
:::

## Code Location

The I2C test code is located at `/app/40pin_samples/test_i2c.py` on the board.

## Test Method

- Run the test program `python3 /app/40pin_samples/test_i2c.py`

- It first lists the I2C buses enabled in the current system
- Enter a bus number to scan which peripherals are connected on the current bus
- Enter a peripheral address (hexadecimal number), and the test program reads one byte of data from that peripheral

## Test Code

```python
#!/usr/bin/env python3

import sys
import signal
import os
import time

# Import i2cdev
from i2cdev import I2C

def signal_handler(signal, frame):
    sys.exit(0)

def i2cdevTest():
    bus = input("Please input I2C BUS num (default 0):").strip() or "0"
    if not bus.isdigit():
        print("Invalid I2C BUS num: %s" % bus)
        return

    os.system('i2cdetect -y -r ' + bus)
    device = input("Please input I2C device num(Hex, e.g. 51):").strip().lower()
    if device.startswith("0x"):
        device = device[2:]
    try:
        device_addr = int(device, 16)
    except ValueError:
        print("Invalid I2C device hex: %s" % device)
        return

    print("Read data from device 0x%x on I2C bus %s" % (device_addr, bus))
    i2c = I2C(device_addr, int(bus))
    value = i2c.read(1)
    i2c.write(value)
    print("read value=", value)
    i2c.close()

if __name__ == '__main__':
    signal.signal(signal.SIGINT, signal_handler)
    print("Starting demo now! Press CTRL+C to exit")
    print("List of enabled I2C controllers:")
    os.system('ls /dev/i2c*')
    while True:
        i2cdevTest()
```

## FAQ

### Scan results are all `--`

**Reason**: No device is attached to the current I2C bus, or the bus number is selected incorrectly.

**Solution**: Confirm that the peripheral is connected correctly and its address is correct; use `i2cdetect -y -r <bus>` to confirm the bus number.

### `OSError: Remote I/O error` is reported

**Reason**: The specified device address gets no response on this bus.

**Solution**: First use `i2cdetect` to scan and confirm the actual address of the device, then enter the correct address.
