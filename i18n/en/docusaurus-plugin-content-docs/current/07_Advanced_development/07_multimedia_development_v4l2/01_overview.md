# Multimedia Development Guide (V4L2 Interface)

This section describes multimedia development on RDK S100/S600 using the standard Linux V4L2 framework. It complements the proprietary HBN interface covered in the [Multimedia Development Guide (HBN Interface)](/Advanced_development/multimedia_development), and targets developers who prefer the open-source V4L2 toolchain and ecosystem for video capture and processing.
