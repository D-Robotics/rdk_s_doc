# GDC API

## Overview

GDC (Geometric Distortion Correction) is for camera image geometric distortion correction and stitching. GDC has no standalone function API; it is driven by config structs (board `hb_gdc_cfg.h`: `gdc_config_t`/`gdc_settings_t`) describing input/output geometry. The config binary is generated by `hbn_gen_gdc_cfg` (see 5.5.1.6 VPF/PYM) and set into the HBN vnode GDC channel via `hbn_vnode_set_ochn_attr`.

## Abstraction

- `gdc_config_t`: per-stream GDC config — input/output width/height, stride, plane count, split mode (`div_width`/`div_height`), `sequential_mode`, etc.
- `gdc_settings_t`: GDC settings — `gdc_config_t` array + the config binary ion share id (`binary_ion_id`) and physical address offset (`binary_offset`).
- The config binary is generated by `hbn_gen_gdc_cfg` (`hbn_vpf_interface.h`) from `param_t`/`window_t`, and freed by `hbn_free_gdc_cfg`.

## Call flow

1. Prepare `gdc_config_t`/`gdc_settings_t` (input/output geometry).
2. `hbn_gen_gdc_cfg` generates the config binary (see 5.5.1.6 VPF/PYM).
3. Open the GDC module via an HBN vnode and set the config with `hbn_vnode_set_ochn_attr`.
4. `hbn_vnode_start` starts; output frames are fetched via `hbn_vnode_getframe`; free the binary with `hbn_free_gdc_cfg` when done.
