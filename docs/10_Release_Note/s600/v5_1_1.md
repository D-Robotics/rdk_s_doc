# RDKS600_LNX_SDK_V5.1.1

**发布日期：** 2026-10-23

## 1. 主要信息

RDK S600 V5.1.1 发布内容包括：

| 描述 | 支持的版本 |
| --- | --- |
| 支持编译的 Host 机版本 | Ubuntu 20.04（x64） |
| 支持烧录的 Host 机版本 | Ubuntu 18.04（x64），Ubuntu 20.04（x64），Ubuntu 22.04（x64） |
| 支持的 Bootloader 版本 | U-Boot 2022.04 |
| 支持的板端根文件系统 | RDKOS V5.1.1（基于 Ubuntu 24.04 (noble)） |
| 支持的板端 Linux 内核版本 | 6.1.158-rt58-DR-5.1.1 |
| 支持的 MCU 版本 | V2.0.3 |
| 支持的 ARM 架构 | aarch64 |
| 交叉编译工具链 | arm-gnu-toolchain-13.2.Rel1（[ARM GNU Toolchain 官方下载页](https://developer.arm.com/downloads/-/arm-gnu-toolchain-downloads)） |

板端默认账户：`sunrise` / 默认密码：`sunrise`。

## 2. 本次发布包含的主要功能更新/变更

### 2.1 启动与存储

- 支持 U 盘升级，升级过程提供 LED 闪烁提示；
- 优化 UFS 读写；
- 提升 fastboot 烧录速率；
- 优化 eMMC 颗粒兼容性。

### 2.2 ACore

#### 2.2.1 根文件系统

- 支持加载自行编译的未签名内核模块；
- 优化系统实时性配置；
- 修复根文件系统软件包安装缺失问题；
- 修复桌面快捷方式与系统应用无法打开的问题；
- 修复 X11 会话启动异常。

#### 2.2.2 Camera

- 新增 sc233hgs 模组驱动，并适配 NS6012 / NS6603 串行器；
- 新增 metic serdes 支持；
- 新增 Intel RealSense D405G 与 ORBBEC Gemini 305G 支持；
- 适配 D457 硬件时间同步（esync）模式；
- 新增多 deserial 接口，支持多个 MIPI host 混合出流。

#### 2.2.3 Codec

- 新增 VPU 多核示例。

#### 2.2.4 LSIO / CAN

- 支持以 socketcan 方式访问 MCU 域 CAN 接口；
- CAN 支持扩展帧与远程帧收发；
- 支持设置 GPIO 初始电平；
- 优化 SPI 传输性能。

#### 2.2.5 Log

- 优化日志服务启动时机。

#### 2.2.6 Ethernet / EtherCAT

- 新增 VLAN 隔离支持；
- EtherCAT 主站支持将内核线程绑定到指定 CPU 运行。

#### 2.2.7 无线与时钟

- 系统时间同步与电池供电的 RTC 交互。

#### 2.2.8 音频

- 支持 I2S 单工与全双工模式，I2S MCLK 输出 24.576MHz。

#### 2.2.9 显示

- 优化显示热插拔检测稳定性。

### 2.3 MCU

#### 2.3.1 CAN

- CAN 支持扩展帧与远程帧收发。

#### 2.3.2 LIN

- 新增 LIN 支持。

#### 2.3.3 EtherCAT

- 新增 EtherCAT 多 Byte 收发 sample；
- 提升代码稳定性。

## 3. 本次发布包含的重点问题修复

### 3.1 ACore

#### 3.1.1 系统与存储

- 提升 PCIe 稳定性与兼容性，修复挂起/恢复、参考时钟与设备枚举异常；
- 扩展 PCIe 可用地址范围；
- 优化 NVME 兼容性；
- 提升 fastboot 烧录稳定性，修复烧录中断后的异常。

#### 3.1.2 相机与多媒体

- 修复多路 GMSL 场景出流卡死的问题；
- 修复 ISX031 模组适配问题；
- 修复多媒体模块句柄泄漏问题。

#### 3.1.3 音频

- 修复 24bit 录音异常的问题；
- 修复桌面音频服务使用问题；
- 修复多声道默认增益设置不一样的问题；
- 修复单声道音频播放无声音的问题。

#### 3.1.4 时间同步与网络

- 修复以太网 PTP E2E 授时异常的问题。

### 3.2 MCU

#### 3.2.1 系统

- 修复 MCU 定时器精度问题。

#### 3.2.2 外设

- 修复 MCU CAN ID 过滤器问题。

## 4. 已知问题

### 4.1 RDK OS

- 部分 Ubuntu 应用在 GPU 加速下因页大小不匹配崩溃；
- 在不插入 HDMI 线时，RDK S600 的桌面系统（GDM3）会默认回退为 X11 渲染，S600 目前不支持 X11 的 GPU 加速，回退后会使用 CPU 渲染，导致 CPU 占用升高；
- 部分 RDK S600 万兆网口启动后有性能问题，需要进行固件下载成功后才能支持万兆性能；
- WiFi 不支持 STA 模式和 AP 模式同时使用。

### 4.2 MCU SDK

- 目前不支持锁步解锁。
