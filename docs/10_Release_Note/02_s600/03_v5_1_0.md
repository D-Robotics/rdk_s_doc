# RDKS600_LNX_SDK_V5.1.0

**发布日期：** 2026-06-12

## 1. 主要信息

**RDK S600 V5.1.0** 发布内容包括：

| 描述 | 支持的版本 |
| --- | --- |
| 支持编译的 Host 机版本 | Ubuntu 20.04 (x64) |
| 支持烧录的 Host 机版本 | Ubuntu 18.04 (x64)，Ubuntu 20.04 (x64)，Ubuntu 22.04 (x64) |
| 支持的 Bootloader 版本 | U-Boot 2022.04 |
| 支持的板端根文件系统 | RDK OS V5.1.0（基于 Ubuntu 24.04 (noble)） |
| 支持的板端 Linux 内核版本 | 6.1.158-rt58 |
| 支持的 ARM 架构 | aarch64 |
| 交叉编译工具链 | arm-gnu-toolchain-13.2.Rel1<br/>https://developer.arm.com/-/media/files/downloads/gnu/13.2.rel1/binrel/arm-gnu-toolchain-13.2.rel1-x86_64-aarch64-none-linux-gnu.tar.xz |

板端默认账户：`sunrise` / 默认密码：`sunrise`。

## 2. 本次发布包含的主要功能更新/变更

- 由于支持 NVMe 启动，Flash 分区表发生变化，本次更新必须整烧；
- 基于合规需求，系统内 Ubuntu 相关字段被替换为 RDK OS；
- 支持板端 ACore 网口的默认 MAC 使用板端 eeprom 内保存的地址；
- boardid 中的 ADC4/5 的档位 0x4/0x5/0x6 范围变宽，取消 0x7 档位，详情请看硬件参考设计。

### 2.1 硬件支持
- 支持 V1P0 版本硬件；
- 支持 NVMe 启动。

### 2.2 ACore
#### 2.2.1 根文件系统
- 修改系统默认网络配置提供方案，符合 Ubuntu 24.04 NetworkManager 及 Netplan 的配置规则：主机厂默认配置以 `/usr/lib/NetworkManager` 目录下的文件为准，所有网络管理最终配置文件由 Netplan 管理；
- 支持 hobot-io 及其 sample 的功能移植。

#### 2.2.2 Camera
- 新增 hbn 框架下，shw3h 和 shw3f 模组驱动；
- 新增 hbn 框架下，明瞐科技 MC30E0Z23-00-03 模组驱动；
- 支持奥比中光 335LG 深度相机。

#### 2.2.3 LSIO
- 支持 ACore 侧 CAN（C + Python）测试用例；
- 支持 ACore 侧 UART 和 SPI 的使用。

#### 2.2.4 Log
- kernel log 存储改由 Ubuntu 原生的 rsyslog 维护，详细描述参考[文档](/Advanced_development/system_software/log_introduction#log-内容)

#### 2.2.5 Display
- 新增 LT9611UXD 的完整支持；
- 优化对多种屏幕的显示兼容性。

#### 2.2.6 Ethernet / EtherCAT
- U-Boot 增加 eth0 (gmac2) 网口驱动支持；
- 默认支持 EtherCAT native 驱动 (ec_hobot)；
- 修复切换 10M 网口速率失败问题。

### 2.3 OTA
- 由于分区表发生变更，V5.0.1 无法通过 OTA 升级到 V5.1.0，如需升级请手动烧录，同版本的升级不受影响。

### 2.4 MCU
#### 2.4.1 SBL 镜像
- 新增 SBL 的 GCC 编译支持；
- 新增 SBL 的 CPU 异常处理信息。

#### 2.4.2 OS 镜像
- 新增 EL1 Undefine 类型异常处理信息；
- 新增 OS CpuLoad 功能支持；
- 性能优化，cache 区域变更：由 sram 全局 uncached 改为局部 cached（只读数据区域/代码段/CPU 栈）。

#### 2.4.3 EtherCAT
- 支持 SOEM EtherCAT 主站。

#### 2.4.4 CAN
- 支持多路 CAN 透传 sample。

### 2.5 Power
- 支持 GPIO 中断触发 PMIC_mon 功能，报障 PMIC 出现的问题。

### 2.6 Xburn 烧录工具
- v1.2.1：支持 OHP 烧录。

### 2.7 Security
- 支持 provision tool 功能；
- 支持 lifecycle 为 OHP 板子的 DFU 启动、镜像下载。

### 2.8 VDSP
- 增加 vdsp 功能支持。

## 3. 本次发布包含的重点问题修复

### 3.1 ACore
#### 3.1.1 时间同步
- 修复 lpwm 配置 ACore ETH PPS 作为 trigger source 源时出图失败以及 camera 获取 trigger_tv 时间没有整百毫秒对齐问题，文档更新。

#### 3.1.2 BPU
- 修复在 BPU 多核推理中，由于需要共享虚拟地址而引发的模型推理失败问题。

#### 3.1.3 Display
- 修复了一处因为休眠唤醒导致的黑屏问题。

#### 3.1.4 GPU
- 修复了一处因为提前释放 buffer 而出现的桌面拖影问题；
- 修复了一处因为 GPU 原因，休眠唤醒失败的问题。

### 3.2 Power
- 修复冷启动过程偶现的 pmic 通信失败问题；
- 修复整机下电流程，MCU 电源未完成下电情况。

### 3.3 MCU
#### 3.3.1 外设
- SPI4 CS1 使用异常修复。

#### 3.3.2 系统
- 修复双精度浮点异常的问题；
- 修复 OS 上下文保存兼容浮点寄存器的问题；
- 调整 mcu1 的内存布局适配现有功能，解决与 IPC 已分配的内存冲突。

## 4. 已知问题

### 4.1 RDK Linux
- 部分 Ubuntu 应用在 GPU 加速下因页大小不匹配崩溃；
- 在不插入 HDMI 线时，RDK S600 的桌面系统 (GDM3) 会默认回退为 X11 渲染，S600 目前不支持 X11 的 GPU 加速，回退后会使用 CPU 渲染，导致 CPU 占用升高；
- 部分 RDK S600 万兆网口启动后有性能问题，需要进行固件下载成功后才能支持万兆性能；
- 使用 NVMe 用作系统盘启动时，不支持休眠唤醒；
- get_multi_vin_data 不支持两个 mipi host 混合出流；
- 修改 /log 为软链接会导致 log 服务持续报错；
- 不支持 RDK S600 开发者套件 Wi-Fi 模组启用 STA+AP 模式。

### 4.2 MCU SDK
- 目前不支持锁步解锁；
- 目前不支持 CAN 拓展帧功能。
