# I2C 应用

RDK S100 在 40PIN 上默认使能 I2C5（物理管脚号 3 和 5）和 I2C4（物理管脚号 27 和 28），IO 电压 3.3V。

:::info

- 40pin 上需要拨动拨码开关来选择使用 I2C5 还是 UART2, 具体细节可以查看下图：

<img src="https://rdk-doc.oss-cn-beijing.aliyuncs.com/doc/img/07_Advanced_development/02_linux_development/driver_development_s100/audio3.png" alt="I2C 应用示意图" style={{ width: '40%', maxWidth: '980px', height: 'auto', display: 'block', margin: '0,0' }} />

管脚定义请参考 [管脚配置与定义](./01_40pin_define.md#40pin_define)

:::

请参阅 `/app/40pin_samples/test_i2c.py`了解如何使用 I2C 的详细信息。

:::tip
以下所提及的管脚仅作示例说明，不同平台的端口值存在差异，实际情况应以实际为准。亦可直接使用`/app/40pin_samples/`目录下的代码，该代码已在板子上经过实际验证。
:::

## 代码位置

I2C 测试代码位于板端 `/app/40pin_samples/test_i2c.py`。

## 测试方法

- 运行测试程序 `python3 /app/40pin_samples/test_i2c.py`

- 首先列出当前系统使能的 I2C 总线
- 通过输入总线号扫描得到当前总线上连接了哪些外设
- 输入外设地址（16 进制数），测试程序会从该外设上读取一个字节的数据

## 测试代码

```python
#!/usr/bin/env python3

import sys
import signal
import os
import time

# 导入i2cdev
from i2cdev import I2C

def signal_handler(signal, frame):
    sys.exit(0)

def i2cdevTest():
    bus = input("Please input I2C BUS num (default 0):").strip() or "0"
    if not bus.isdigit():
        print("Invalid I2C BUS num: %s" % bus)
        return

    os.system('i2cdetect -y -r ' + bus)
    device = input("Please input I2C device num(Hex, e.g. 51):").strip().lower()
    if device.startswith("0x"):
        device = device[2:]
    try:
        device_addr = int(device, 16)
    except ValueError:
        print("Invalid I2C device hex: %s" % device)
        return

    print("Read data from device 0x%x on I2C bus %s" % (device_addr, bus))
    i2c = I2C(device_addr, int(bus))
    value = i2c.read(1)
    i2c.write(value)
    print("read value=", value)
    i2c.close()

if __name__ == '__main__':
    signal.signal(signal.SIGINT, signal_handler)
    print("Starting demo now! Press CTRL+C to exit")
    print("List of enabled I2C controllers:")
    os.system('ls /dev/i2c*')
    while True:
        i2cdevTest()
```

## 常见问题

### 扫描结果全为 `--`

**原因**：当前 I2C 总线上没有挂载设备，或总线号选择错误。

**解决**：确认外设已正确连接且地址正确；用 `i2cdetect -y -r <bus>` 确认总线号。

### 提示 `OSError: Remote I/O error`

**原因**：指定的设备地址在该总线上无应答。

**解决**：先用 `i2cdetect` 扫描确认设备实际地址，再输入正确地址。
