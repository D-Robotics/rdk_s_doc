# IMU 应用

本示例演示读取 IMU 传感器（加速度计 + 陀螺仪）数据。RDK S100 板端支持两款 IMU 芯片：**BMI088**（6 轴）和 **ICM42688**（6 轴），并提供两种读取方式：

- **IIO 子系统**（`sample_imu_iio`）：通过 `/sys/bus/iio/devices/` 读取，统一支持 BMI088 与 ICM42688，用 `-n` 指定芯片。
- **input 事件子系统**（`sample_imu_input`）：通过 `/dev/input/eventX` 读取驱动上报的 MSC 事件。

:::tip
该示例基于 Linux IIO/input 子系统读取数据，随 RDK S100 镜像提供；源码位于 `hobot-multimedia-samples` 的 `multimedia_samples/sample_imu/` 目录。
:::

## 环境准备

- 开发板已烧录 RDK OS 并启动
- IMU 传感器已连接到开发板（通过扩展板或主板 I2C/SPI），且对应驱动已加载：
  - IIO 方式：在 `/sys/bus/iio/devices/` 下能看到 `iio:device*` 节点，`name` 为 `bmi08a` / `icm42688-gyro` / `icm42688-accel` 等
  - input 方式：在 `/sys/class/input/` 下能看到对应的 input 设备，并存在对应的 `/dev/input/eventX`

## 代码位置

板端路径：`/app/multimedia_samples/sample_imu/`

```text
sample_imu/

│   ├── Makefile
│   ├── sample_imu_iio.c     # 主程序：解析参数 + 交互式读取

│   └── icm42688.c           # ICM42688 驱动实现

    ├── Makefile

```

源码路径：`hobot-multimedia-samples` 的 `multimedia_samples/sample_imu/`

## 使用方法

### 方式一：IIO 读取（sample_imu_iio）

`sample_imu_iio` 通过 IIO sysfs 读取数据，一个程序支持多款芯片，用 `-n` 指定传感器名。支持的传感器：`bmi08a`、`bmi08x`、`icm42688-gyro`、`icm42688-accel`。

> S100 上 BMI088/ICM42688 的加速度与角速度是分离的 IIO 设备，因此一个 `iio:device*` 只含一种通道（accel 或 gyro），需分别用对应的 `-n` 读取。

```bash
cd /app/multimedia_samples/sample_imu/sample_imu_iio
./sample_imu_iio -n icm42688-gyro
```

不指定 `-n` 时，程序会自动探测第一个可用的传感器作为默认值。

程序启动后进入交互式命令行，输入命令读取数据：

- `g`：获取一帧 IMU 数据
- `l`：获取多帧 IMU 数据，需输入帧数
- `q`：退出程序
- `h`：显示帮助信息

### 方式二：input 事件读取（sample_imu_input）

`sample_imu_input` 通过 Linux input 子系统读取驱动以 MSC 事件上报的加速度 + 角速度 + 时间戳。

```bash
cd /app/multimedia_samples/sample_imu/sample_imu_input
./sample_imu_input
```

程序会自动扫描 `/sys/class/input/` 下的 input 设备并打开对应的 `/dev/input/eventX`；也可显式传入设备路径 `./sample_imu_input /dev/input/event0`。运行后持续输出数据帧，按 `Ctrl+C` 退出。

## 运行效果

### IIO 方式

运行 `./sample_imu_iio -h` 查看帮助信息：

```text
Usage: sample_imu_iio [OPTIONS]
Options:
  -n <imu_name>         Specify IMU name (default: icm42688-gyro)
  -h                    Show this help message
Supported sensors: bmi08a bmi08x icm42688-gyro icm42688-accel
```

以 ICM42688 为例，启动后输入 `g` 读取一帧数据：

```text
Using IMU: icm42688-gyro

=== Detected IIO Devices ===
  Device: iio:device1     | Name: icm42688-accel
  Device: iio:device2     | Name: icm42688-fsync
  Device: iio:device0     | Name: icm42688-gyro
============================

***************  Command Lists  ***************
 g    -- Get a single frame of imu data
 l    -- Get multiple frames of imu data
 q    -- Quit the program
 h    -- Print this help message
Enter command: Data received (Frame 1):
  Accelerometer: [4.079719, -0.272939, -7.991845] m/s²
  Gyroscope:     [0.056459, -0.211988, -0.156594] rad/s
  Timestamp:     494643:52:25.586.280
```

未接入 IMU 传感器（或对应 IIO 驱动未加载）时，程序检测失败并退出：

```text
Error: no supported IMU device was detected.
Supported sensors: bmi08a bmi08x icm42688-gyro icm42688-accel
```

> 上述数据帧为实测输出示例（加速度单位 m/s²、角速度单位 rad/s），具体数值随传感器姿态与量程变化；时间戳为驱动上报的微秒时间戳，按 `hh:mm:ss.mmm.uuu` 格式化输出，小时位可能较大（累计运行时间）。

### input 方式

接入 IMU 后运行 `./sample_imu_input`，程序自动探测设备并持续输出数据帧，格式如下：

```text
========================================
BMI088 input reader (unified MSC code)
Device path: /dev/input/event0
Press Ctrl+C to exit
========================================

ACC(0,0,98) | GYRO(0,0,0) | TS:0 ns | Lost: 0 | EventCount: 1 | up_count: 1 | lower_count: -
```

未接入 IMU 时，程序无法自动探测到设备，回退到默认路径并报错：

```text
Warning: could not auto-detect BMI088 input device, using /dev/input/event1
/dev/input/event1: No such file or directory
```

## 常见问题

### 程序检测不到 IMU 直接退出

**现象**：IIO 方式输出 `Error: no supported IMU device was detected.` 并退出；input 方式输出 `could not auto-detect BMI088 input device` 并报 `No such file or directory`。

**原因**：未接入对应 IMU 传感器，或对应驱动未加载。

**解决**：确认 IMU 已连接，检查 `/sys/bus/iio/devices/`（IIO 方式）或 `/sys/class/input/`（input 方式）下是否存在对应节点。

### 如何读取非默认型号的传感器

**现象**：需要读取 BMI088 或 ICM42688 的某一轴数据，但不确定如何指定。

**原因**：IIO 方式不指定 `-n` 时使用自动探测到的默认传感器。

**解决**：通过 `-n` 指定传感器名，支持 `bmi08a`、`bmi08x`、`icm42688-gyro`、`icm42688-accel`。S100 上 accel 与 gyro 是分离的 IIO 设备，读取角速度用 `icm42688-gyro`，读取加速度用 `icm42688-accel`。

### IIO 方式与 input 方式的区别与选择

**区别**：IIO 方式（`sample_imu_iio`）通过 sysfs 读取，统一支持 BMI088 与 ICM42688，按帧交互读取；input 方式（`sample_imu_input`）通过 input 事件读取驱动上报的 MSC 数据，持续输出。

**选择**：需要驱动上报的连续事件流时可选 input 方式，按需交互读取则选 IIO 方式。
