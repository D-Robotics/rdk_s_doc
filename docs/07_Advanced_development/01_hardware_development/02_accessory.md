# 7.1.2 配件清单

```mdx-code-block
import DocScope from '@site/src/components/DocScope';
```

认证配件清单是指经过 D-Robotics 官方认证，可以适配开发板的第三方配件清单。主要包含基础配件(电源、外壳、散热器)、摄像头、显示屏等类别，清单内容会不定期更新，逐步添加更多的配件型号。

:::info

- 配件清单根据适配情况，定期更新

:::
